# Boceto: Compras con los criterios de Soy (2026-11-23)

Copia del boceto que aprobó Soy. Se ve en https://claude.ai/artifact/NLjRX7gLTMRdP7kVjU27Ng (pedile a Soy que te lo comparta).

Estos archivos son la fuente del boceto y quedan como registro. No se abren solos en el navegador y **no son código del sistema**: no se copian a `app/` ni a `components/`.

- `Main.dc.html`: nueva orden de compra en una pantalla (proveedores a la izquierda, artículos al medio, la orden a la derecha).
- `NuevaFactura.dc.html`: alta de factura en un modal corto.
- `Facturas.dc.html`: listado con los proveedores a la izquierda y los estados.
- `Pagos.dc.html`: panel «Registrar pago» sin scroll.
- `Lista.dc.html`: cargar una lista de precios con la planilla compacta.

Todos los datos son inventados. Si el boceto y el prompt no coinciden, manda el prompt: `../2026-11-23-correcciones-compras.md`. El prompt suma cosas que el boceto no muestra (orden de pago completa, celular, importación de listas): mandan las decisiones escritas.
